# GG Esports v1.0.0

## About this release

GG Esports v1.0.0 is the first published Android release for the official GG Esports community experience. It brings the project’s official community links, esports updates, and support channels together in one accessible Android app.

**Version:** 1.0.0  
**Platform:** Android

## Verified features

- Access to the official GG Esports WhatsApp Community.
- Access to the official GG Esports WhatsApp Channel.
- Community-oriented esports announcements and updates.
- Direct links to official GG Esports social channels and support.

## What’s new

- Initial public Android release.
- Official GG Esports community and support links.
- GitHub release distribution through the `GG_Esports_User.apk` asset.

## Download

Download **GG_Esports_User.apk** from the **Assets** section below this release. Use the official GitHub release page to confirm the version before installing.

## Android installation

1. Download `GG_Esports_User.apk` from this release’s **Assets** section.
2. Open the downloaded file on your Android device.
3. If prompted, temporarily allow your browser or file manager to install unknown apps.
4. Review the prompt and install GG Esports.
5. Disable the temporary install permission after installation if you do not need it.

Only install the APK from the official GG Esports GitHub repository. This project is not affiliated with, sponsored by, or endorsed by Garena or Free Fire, and it does not claim Google Play verification.
