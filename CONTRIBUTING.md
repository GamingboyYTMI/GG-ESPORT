# Contributing to GG ESPORT

Thank you for helping improve the public GG ESPORT repository.

## Repository scope

This is currently a binary distribution and documentation repository. It contains the public landing page, release guidance, and community links; private application source code is not part of this repository.

## Safe contributions

- Improve documentation, accessibility, responsive layout, or link accuracy.
- Report reproducible installation and public website issues.
- Keep claims limited to behavior confirmed by public release notes or project-owner confirmation.

## Never submit

Do not open a pull request containing private application source code, APK signing keys, keystores, Firebase service-account files, API secrets, credentials, admin builds, or private user data. Do not upload APKs or create releases through a documentation pull request.

## Pull requests

Keep changes focused, explain how you tested them, and avoid changing historical release assets. Before submitting, check that download links still use the dynamic latest-release URL and that the WhatsApp links remain unchanged.
