# Frequently Asked Questions

## Where do I download the app?

Use the [latest release page](https://github.com/GamingboyYTMI/GG-ESPORT/releases/latest) and download the User APK listed under Assets. Avoid outdated direct APK links.

## Why does Android ask for permission?

An APK installed outside Google Play may require the browser or file manager to be temporarily allowed to install unknown apps. Enable that permission only for the trusted download source, then disable it after installation.

## How do I update?

Download the newest User APK from the latest release and install it over the current app. If the update is rejected, verify the source and signing identity before considering an uninstall.
