# Installing GG ESPORT on Android

1. Open the [latest GitHub release](https://github.com/GamingboyYTMI/GG-ESPORT/releases/latest).
2. Download the **User APK** from the release **Assets** section.
3. Open the downloaded APK on your Android device.
4. If Android requests permission to install from that source, allow it temporarily for the browser or file manager used for the download.
5. Review the Android prompt and install the app.
6. Disable the temporary “install unknown apps” permission after installation if it is no longer needed.

## Updating

Download the APK from the newest release and install it over the existing app. Keeping the existing installation may preserve compatible local data. If Android refuses the update, confirm that both APKs came from the official release page and use the same signing identity. Removing the old app may remove local data.

Only install APKs obtained from the official repository release page. This project does not promise Google Play availability or verification.
